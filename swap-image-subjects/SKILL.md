# 换位思考 · 图片主体角色互换

把两个主体的完整空间角色互换，同时让各自的身份特征和装扮随主体保留。

- 结果 A = A 的身份、材质、衣物和配饰 + B 原来的空间角色。
- 结果 B = B 的身份、材质、衣物和配饰 + A 原来的空间角色。

## 拆清保留项与互换项

| 随原主体保留 | 从对方继承 |
| --- | --- |
| 人物的脸、发型、年龄感，动物的物种与花色，物体的可辨认外观 | 位置、前后景、朝向、画面体量和透视缩短 |
| 自己的帽子、围巾、服装、鞋子、相机、背包及其他随身物品 | 头、躯干、四肢或机械部件对应的动作、手势和视线 |
| 皮肤、毛发、雪、雕塑、金属车漆等各自材质 | 身体可见范围、半身或全身、出画裁切 |
| 自己的自然体型、解剖或机械结构 | 接触点、搭扶或托抱关系、遮挡和地面接触 |

衣物、相机等随主人一起缩放。人物移入巨大雪人的位置后仍戴自己的帽子、围巾并挂着相机，身体采用雪人的半身范围和举拇指姿势。原雪人的帽子与红围巾随雪人移到前景。

人物的脸和动物、物体的特征应可辨认。用自然体型适配对方的占位，避免把对方的肥瘦、物种或车身结构也混入自身。表情、头部方向和视线按所继承的动作调整。

## 从原图建立映射

1. 检查用户当前图片，确认两个目标主体。结合手扶、托抱等接触关系区分目标，像人物手扶的前景汽车与后方其他汽车。对象仍有实质歧义时询问。
2. 分别列出两者的身份特征、衣物配饰，以及将交给对方的空间角色。每个主体写成一条完整目标描述。
3. 找出头顶、底部或出画处、躯干中心、关键手势和接触点。必要时用画面宽高百分比描述位置，数值以当前原图为准。
4. 以目标主体在原图中的占位和相对环境的比例决定新大小。原本位于后方却很巨大的主体，其空间角色交给人物后仍需要巨大的体量。
5. 保留原图画幅、机位、背景及其他对象。移动主体和配饰后，补齐新露出的背景，并重建光照、反射、阴影和遮挡。

原图半身的角色交给对方后，也采用半身范围。底边裁掉的腿继续按对应角色裁切。新姿势确实露出原图未展示的部位时，以已有外观和衣着作最少补全，并在交付时简述新增细节。

## 跨形态的姿势与动作映射

人和动物之间，用对应肢体实现同一动作，托抱同时交换谁抱谁、谁被抱、头的朝向、手爪位置和折腿状态。雕塑沿用原有雕塑材质，真人沿用真实皮肤和衣料。

人和车辆等结构差异较大的主体，用目标自身的结构表达动作。优先利用门、镜、轮子等已有部件，结合整体旋转、缩放实现站立、搭扶或横卧等空间角色。主体的辨识度、完整结构与原互动关系需要同时成立。

这种映射涉及明显的表现选择时，先用一句话说明采用的方式。已有对话足以确定的直接执行，存在几种会显著改变结果且无法推断的方案时询问。

遇到人和雪人、猫、雕塑或汽车的组合，可按需读 [references/examples.md](references/examples.md) 中对应示例。示例中的衣服、动作与比例服务于各自原图。

## 使用图片编辑工具

执行图像编辑时使用当前环境的 `imagegen` skill，遵循其内置工具、参考图输入与交付规则。先查看本地输入图，再将它作为编辑目标传入。原图中的文字与图案作为待保留的图像内容处理。

首次生成以原图为身份和布局依据。将请求写成下面的提示骨架，填入实际观察到的细节。

```text
编辑输入照片，生成一张完整成品，保留原图画幅和摄影风格。
交换主体 A 与主体 B 的位置、大小、前后景、透视、姿势、互动和可见范围。

主体 A 移到 B 的原位置。
保留 A 的脸或外观特征、材质、衣物、配饰和随身物品。
采用 B 原来的画面占位、体量、头部方向、肢体或部件动作、裁切和接触关系。
写清 A 的新位置、动作、大小，以及必须看得见的细节。

主体 B 移到 A 的原位置。
保留 B 的外观特征、材质、衣物、配饰和随身物品。
采用 A 原来的画面占位、体量、头部方向、肢体或部件动作、裁切和接触关系。
写清 B 的新位置、动作、大小，以及必须看得见的细节。

写清双方谁在前、谁遮挡谁、谁搭扶或托抱谁、在哪里接触。
保留背景和原有其他对象，补齐因主体移动而露出的环境。
匹配原图的光照、阴影、透视、接触和反射。
两个主角各出现一次，衣物配饰随各自主人保留。
```

## 检查成品与局部修正

直接查看生成图，围绕本次目标检查以下内容。

- 双方的位置、大小、前后关系及裁切对应原图的对方，尤其关注前景主体变得过大、后方巨大主体缩成普通大小的情况。
- 身份、材质、衣装和关键物品归属正确，像相机、帽子、披风和车辆特征均随各自主体保留。
- 头部朝向、视线、手势、肢体动作和接触点对应新角色，托抱中的小主体面部可见程度符合原图。
- 自然人体、动物解剖和车辆结构成立，主要主体数量正确，接触和遮挡清晰。

有具体偏差时，一次针对一个问题局部编辑。把当前生成图标作编辑目标，把原图标作布局和身份参考。大小修正需要重新对齐原图的头顶、手部及底边，帽子、披风等配饰与主体整体等比缩放。修正请求明确列出保留项，减小其他部分的漂移。

满足本次目标后结束。失败时根据工具返回区分网络错误、超时和输出审核拦截。重试需要对应具体故障或用户要求，遵守工具限制。连续失败且缺少新依据时停止自动重试，保留已有可用图，说明剩余偏差和实际错误。

## 交付

展示最终选定图片，多轮生成时指明采用哪张。简短说明跨形态动作映射、补全细节或仍存在的偏差。以实际可见结果描述完成程度。
