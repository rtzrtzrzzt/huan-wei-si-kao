# 换位思考

**同一张照片，换一个角色看世界。**

一份用于 Codex 的图片主体角色互换 Skill。让照片中的两个主角带着各自的脸、材质、衣物与配饰，交换位置、大小、前后景、姿势、互动关系和身体可见范围。

[一键下载完整 Skill](https://github.com/rtzrtzrzzt/huan-wei-si-kao/releases/latest/download/huan-wei-si-kao.zip) · [个人网站](http://www.rentianzhuo.com/knowledge) · [MIT 许可证](LICENSE)

中文展示名为 **换位思考**；技能标识与安装文件夹为 `swap-image-subjects`。

## 它会怎样互换

| 随各自主体保留 | 交给对方的空间角色 |
| --- | --- |
| 人物的脸和发型，动物的物种花色，物体的辨识特征 | 位置、体量、前后景、朝向与透视 |
| 自己的帽子、衣服、围巾、鞋子、相机与背包 | 肢体动作、手势、头部方向与视线 |
| 真实皮肤、毛发、雪、雕塑、金属等材质 | 半身或全身范围、出画裁切 |
| 自己的自然体型与结构 | 托抱、搭扶、遮挡与地面接触 |

例如，人与巨大雪人互换后，人物会带着自己的黑帽、灰围巾和相机进入后方巨大的半身位置，双手举起拇指；雪人带着白礼帽、红围巾来到前景。相机与衣物会随主人一起缩放。

支持人物与动物、雕塑、雪人、机器人和车辆等组合。形态差异较大时，用主体自身的肢体或部件表达对方的动作；需要解释的映射和新补全的细节会在交付时说明。

## 安装

需要一个已启用图片编辑能力的 Codex 环境，以及该环境中的 `imagegen` Skill。此仓库提供编辑工作方法，图像生成由当前环境的图片工具执行。

1. 点击上方“一键下载完整 Skill”。
2. 将 ZIP 解压到本机 Skills 目录，保留整个 `swap-image-subjects` 文件夹。
3. 新建 Codex 任务，以发现刚安装的技能。

macOS / Linux 示例：

```sh
cd ~/Downloads
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
unzip huan-wei-si-kao.zip -d "${CODEX_HOME:-$HOME/.codex}/skills"
test -f "${CODEX_HOME:-$HOME/.codex}/skills/swap-image-subjects/SKILL.md"
```

也可以克隆本仓库，将其中的 `swap-image-subjects` 文件夹放入 Skills 目录。

## 使用

把原图附在对话里，明确说出要互换的两个主体：

```text
使用 $swap-image-subjects，互换这张照片中的人物和雪人。
交换位置、大小、前后景、透视、姿势、互动关系和身体可见范围。
保留各自的脸、外貌、材质、服装、配饰与随身物品。
保留原图画幅、机位和背景，重建接触、遮挡与光影。
```

如果画面中有多个相似对象，可以用位置和接触关系定位：

```text
使用“换位思考”，互换人物与手扶的前景汽车。
背景中的其他车辆保持原来的位置。
```

批量图片可逐张指定对应关系，例如“图一小孩和老虎，图二女孩和绿巨人”。

## 方法与检查

技能会先确认两位主角，建立身份与空间角色的对应关系，再根据原图的头顶、手脚、底边和接触点确定新位置与比例。编辑时使用原图作为布局和身份参考，并保留原图背景、画幅与机位。

生成后重点查看：

- 前后景与体量是否真正对应原图中的对方。
- 脸、衣物、配饰、材质和随身物品是否仍属于正确的主体。
- 手势、托抱、搭扶、遮挡和接触是否清楚、自然。
- 原图的半身范围和底边裁切是否得到保留。

有具体偏差时，以当前成品为编辑目标、原图为参考做局部修正。原图没展示的部位因新姿态而露出时，按已有衣着做少量补全并说明。最终质量受原图和图片模型影响，需要直接查看成品。
